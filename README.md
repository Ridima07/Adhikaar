# Adhikaar

Adhikaar is an AI-powered government scheme discovery and application
assistance platform that helps citizens find relevant schemes, understand
their eligibility, prepare required documents, and recover from application
rejection.

## Problem

Government schemes are often difficult to discover because information is
fragmented across multiple portals. Citizens may also struggle to understand
eligibility criteria, required documents, application procedures, and reasons
for rejection.

## Core Features

- Personalized government scheme recommendations
- Explainable eligibility results
- Benefit gap analysis
- Required document checklist
- Application readiness assessment
- Official application portal redirection
- Rejection recovery guidance
- RAG-based scheme explanations
- Multilingual assistance

## Tech Stack

- Frontend: React
- Backend: FastAPI
- Database: PostgreSQL/MongoDB
- AI: LLM + RAG
- Eligibility: Rule-based eligibility engine
- Document Intelligence: OCR and document validation
